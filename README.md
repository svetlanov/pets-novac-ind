# Novak Pets

Интерактивное веб-приложение для ведения базы данных питомцев, включающее функции создания, редактирования, просмотра и удаления карточек с полной информацией о каждом животном. Разработано с использованием React, Redux Toolkit и MockAPI.

---

## 1. Установка и запуск проекта

### Требования:

- Node.js (v16+)
- npm или yarn

### Установка:

1. Клонируйте репозиторий:

```bash
git clone https://github.com/svetlanov/pets-novac-ind.git
cd pets-novac-ind
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите приложение:

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## 3. Описание проекта

### Цель:
Создать визуально привлекательное и функциональное приложение для управления информацией о домашних животных, позволяющее отслеживать настроение и характеристики питомцев.

### Основной функционал:

- **CRUD (создание, просмотр, редактирование, удаление) карточек питомцев**
- **Редактирование карточки по ссылке `/edit/:id`**  
  – с догрузкой данных по `id`, если питомец отсутствует в локальном `store`
- **Сортировка по возрасту**
- **Фильтрация по типу животного**
- **Поиск по имени**
- **Предпросмотр изображения питомца (по ссылке)**
- **Выбор темперамента** из списка (игривый, спокойный, разговорчивый и т.д.)
- **Глобальное состояние через Redux Toolkit + Redux store**
- **Скелетоны и loaders** при загрузке карточек и форм
- **Всплывающие уведомления (`react-toastify`)** при действиях пользователя
- **Страница 404 для несуществующих маршрутов**
- **Фоновое видео и вдохновляющий текст на главной**
- **Анимации элементов с помощью `framer-motion`**
- **Адаптивный дизайн под мобильные и планшеты**

##  6. Дополнительные аспекты

- Проект построен на `Vite` для быстрой разработки
- Строгое разделение: `store`, `api`, `actions`
- Использование компонентного подхода (формы, карточки, фильтры, скелетоны)
- Удобно расширяется на новые сущности (например, пользователи, владельцы, вакцинации и т.д.)
