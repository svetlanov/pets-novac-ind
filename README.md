# Novak Pets

Интерактивное веб-приложение для ведения базы данных питомцев, включающее функции создания, редактирования, просмотра и удаления карточек с полной информацией о каждом животном. Разработано с использованием React, Redux Toolkit и MockAPI.

---

## 1. Установка и запуск проекта

### Требования:

- Node.js (v16+)
- npm или yarn

### Установка:

1. Клонируйте репозиторий:

```bash
git clone https://github.com/your-username/mood-tracker-pets.git
cd mood-tracker-pets
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите приложение:

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## 3. Описание проекта

### Цель:
Создать визуально привлекательное и функциональное приложение для управления информацией о домашних животных, позволяющее отслеживать настроение и характеристики питомцев.

### Основной функционал:

- **CRUD (создание, просмотр, редактирование, удаление) карточек питомцев**
- **Редактирование карточки по ссылке `/edit/:id`**  
  – с догрузкой данных по `id`, если питомец отсутствует в локальном `store`
- **Сортировка по возрасту**
- **Фильтрация по типу животного**
- **Поиск по имени**
- **Предпросмотр изображения питомца (по ссылке)**
- **Выбор темперамента** из списка (игривый, спокойный, разговорчивый и т.д.)
- **Глобальное состояние через Redux Toolkit + Redux store**
- **Скелетоны и loaders** при загрузке карточек и форм
- **Всплывающие уведомления (`react-toastify`)** при действиях пользователя
- **Страница 404 для несуществующих маршрутов**
- **Фоновое видео и вдохновляющий текст на главной**
- **Анимации элементов с помощью `framer-motion`**
- **Адаптивный дизайн под мобильные и планшеты**

## 4. Примеры использования

### Список питомцев с фильтрацией и сортировкой:

- Пользователь может:
  - отфильтровать по типу (собака, кошка, попугай…)
  - отсортировать по возрасту (по возрастанию/убыванию)
  - найти питомца по имени



---

### Добавление нового питомца

- Заполняются поля:
  - имя, тип, порода, темперамент, возраст, ссылка на изображение
- Пример изображения: `https://loremflickr.com/300/300/dog`

После нажатия на “Сохранить” ➝ всплывающее уведомление: **“Питомец успешно добавлен!”**

---

### Редактирование питомца

- По адресу `/edit/:id`
- Если питомец не найден в локальном состоянии — данные загружаются с сервера
- Превью изображения автоматически обновляется при изменении ссылки

---

### Удаление питомца

- Нажатие на кнопку “Удалить” вызывает loader (`Удаление...`)
- После удаления — отображается toast: **“Питомец успешно удалён!”**

---

### Главная страница

- Видеофон + вдохновляющий текст:

> **"Питомцы делают наш мир ярче.  
Давай заботиться о них каждый день."**

---

### Страница 404

- Для всех несуществующих маршрутов отображается страница 404 с кнопкой возврата на главную
